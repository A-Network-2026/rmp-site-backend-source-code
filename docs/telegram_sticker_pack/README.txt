A Network Neon Sticker Pack

16 stickers generated in ANT POWER style
- Telegram size PNG: docs/telegram_sticker_pack (100x100)
- Big PNG: docs/telegram_sticker_pack_big (512x512)
- HD Upload PNG: docs/telegram_sticker_pack_hd (512x512, original names)
- Animated GIF: docs/telegram_sticker_pack_gif (512x512 pulse)

Upload to Telegram:
1. Open Telegram and message @Stickers
2. Use /newpack and choose a pack name
3. Add all 100x100 files from docs/telegram_sticker_pack
4. Assign emoji as shown in emoji_mapping.csv
5. Publish and set an optional short name
