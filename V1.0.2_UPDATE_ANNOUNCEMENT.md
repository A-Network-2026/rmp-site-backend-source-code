# A-Network v1.0.2 Update Announcement

We are now implementing Version 1.0.2 as part of our continued development and testing phase.

## Important Notice: System Reset

A full system reset will be conducted with this update. All existing data will be cleared to ensure a clean and accurate environment for comprehensive testing.

## Key Updates

- Introduction of ANTS (Mining System)
- Rewards are distributed in ANET coins
- Deployment of the complete project flow for end-to-end testing

## ANTS vs ANET

- ANTS: The mining mechanism within the application
- ANET: The reward coin earned through mining

The ANET system has already been tested and is functioning correctly. With this update, we are integrating ANTS to provide a full understanding of the project's mechanics.

## Web4 Wallet Creation (Custom)

This release includes custom wallet creation aligned with Web4 migration requirements:

- Wallet display address starts with ANET
- A 12-word recovery phrase is generated for wallet backup
- Wallet creation remains one-wallet-per-user for account integrity

## Tester Instructions

1. Update the application to v1.0.2.
2. Expect all previous data to be reset.
3. Begin a new mining session using ANTS.
4. Ensure notifications are enabled for proper tracking.
5. Create or verify your ANET wallet and securely store the 12-word recovery phrase.
6. Report any issues or bugs through official channels.

## Summary

This update represents the deployment of the complete system architecture, allowing all testers to experience the full functionality of A-Network.

Your feedback remains essential as we move toward public release.
