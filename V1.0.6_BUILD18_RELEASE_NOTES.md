# A Network v1.0.6 Build 18 - Enhanced Territory Visibility Release

**Release Date:** April 26, 2026  
**Version:** 1.0.6+18  
**Build Type:** Production Release  
**Platforms:** Android (APK & AAB)

---

## Overview

This release introduces comprehensive territory visibility enhancements and mining action prominence improvements to the A Network mobile app. Users now have real-time access to network statistics by country/territory with a seamless quick-access interface on the homepage.

---

## New Features

### 1. **Enhanced Territory Overview Dialog** 🌍
- **Click any country flag** on the homepage to see detailed territory statistics
- **4-Metric Display:**
  - **Total Ants:** Registration count for the territory
  - **Network Share %:** Territory's percentage of global network
  - **Active Workers:** Live mining participants in the territory
  - **Sessions in Territory:** Concurrent active sessions
- Clean, formatted card layout with consistent visual hierarchy

### 2. **Top Territories Quick Access** 📍
- **New horizontal scrollable section** on homepage
- **Top 8 countries** displayed with country names and emoji flags
- **One-tap access** to each territory's detailed stats
- Maintains original rotating globe design on page 1

### 3. **Total Registered Network Stats** 📊
- **New stat cards** on homepage showing:
  - Total Registered Users across all territories
  - Total Number of Countries/Territories
- Real-time updates from network data
- Prominent placement alongside mining action button

### 4. **Mining Action Prominence** ⛏️
- **Prominent "Start/Open Ant Work" button** on homepage
- Replaces redundant online user statistics
- Cyan-styled design matching original interface
- Clear status indicator (LIVE/READY)
- Direct access to mining interface with single tap
