# A-Network v1.0.5 Community Release Note

The latest A-Network Android release is now ready for the community.

This update continues the move toward a clearer and safer ecosystem structure across Web2, Web3, Web4, and Web5. The goal of this release is to make the live experience easier to understand while keeping participation rules, wallet language, and community systems clearly separated.

## What Changed In v1.0.5

- Clearer ANTS-first accounting across the app experience
- Improved ANET coin and settlement wording in user-facing screens
- Updated ANTS Program language as a view-only community identity layer
- Stronger separation between Web2 mining, Web3 visibility, Web4 settlement, and Web5 community coordination
- Colony Points (CP) clarified as performance metrics, not coins or guaranteed rewards
- Wallet messaging improved to emphasize user-controlled destination addresses and seed phrase safety
- Updated public documentation and in-app whitepaper summaries for consistency
- Final Android release artifacts generated for APK and AAB deployment

## Community Guidance

- ANTS remains the live accounting unit inside the current Web2 participation flow
- ANET remains the settlement unit used for eligibility, conversion, and broader ecosystem direction
- The ANTS Program is view-only and does not generate coins, payouts, or on-chain status
- Colony Points (CP) reflect activity and performance only
- Web3 wallet addresses are used as destination addresses for controlled distributions or migration routing
- A Network does not store private keys and does not ask for seed phrases to define wallet ownership

## Important Notice

A Network does not guarantee financial returns.

All values, metrics, and any controlled distributions depend on participation, system rules, and network conditions. The platform is designed for ecosystem participation, not speculative investment.

## For The Community

Please update to the latest Android build and continue testing the live experience carefully.

Focus on:

1. Ant Work session flow
2. Wallet visibility and wallet continuity tools
3. ANTS and ANET wording clarity
4. Colony and CP visibility behavior
5. General stability, UI clarity, and bug reporting

Your feedback remains important as A-Network continues moving from Web2 participation toward Web4 settlement and future Web5 community coordination.

Thank you for continuing to build with us.
